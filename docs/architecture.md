# Architecture

What the installer does, step by step, what it leaves running, how the
Nginx files fit together, and which files a re-run keeps, rewrites or
regenerates. How a request reaches your app is in Your app, [Request
flow](app.md#request-flow).

## Install flow

Before anything changes, the installer checks its arguments and settings
(see [Configuration](configuration.md#reference)), that it runs as root,
and takes the lock `/run/bun-installer.lock`; a second run exits 1 here.
Everything after that is logged to `/var/log/bun-installer.log`.

| # | Step | Writes or changes | Skipped by |
| --- | --- | --- | --- |
| 1 | Check the OS and web root | nothing; refuses below Ubuntu 22.04, or a web root that is a dangling symlink | |
| 2 | Update package lists | apt indexes; waits for an apt lock, retries | |
| 3 | Check snapd | nothing; refuses a masked or uninstallable snapd | `SKIP_CERTBOT=1` |
| 4 | Upgrade packages | `apt-get upgrade` (`full-upgrade` with `FULL_UPGRADE=1`) | `SKIP_UPGRADE=1` |
| 5 | Base packages | `curl`, `nginx`, `ufw`, `logrotate` and a few others | |
| 6 | Firewall | UFW policy, rules, enable; never a reset | `SKIP_UFW=1` |
| 7 | Certbot | the snapd package and the `certbot` snap | `SKIP_CERTBOT=1` |
| 8 | Bun | `/usr/local/bin/bun` and `bunx`, verified first | |
| 9 | Service user | system user `bun-app` (no login) | `SKIP_BUN_APP=1` |
| 10 | Sample app | `/srv/app` and `/var/www/app/dist/index.html`, if no app is there | `SKIP_BUN_APP=1` |
| 11 | Cloudflare | updater, its units, first IP list fetch, Nginx files, timer | `SKIP_CLOUDFLARE=1` |
| 12 | Nginx | proxy snippet, map file and the default site; `nginx -t`, restart | site and snippets with `SKIP_BUN_APP=1` |
| 13 | App service | `bun-app.service`, `/etc/bun-app.env`, `/srv/app/data`; restart | `SKIP_BUN_APP=1` |
| 14 | Records | `/var/lib/app-info/application.info`, `INSTANCE_ID` in `/etc/environment` | |
| 15 | Login message | `/etc/update-motd.d/00-custom`; Ubuntu's header and help text moved aside | |
| 16 | Log rotation | `/etc/logrotate.d/bun-installer` | |
| 17 | Summary | nothing; checks the services, exits 1 on a problem | |

- **A failed step stops the run** with `install failed at line N
  (<step>)`. Steps before it stay done, and re-running is safe: done
  steps are skipped or repeated without harm.
- **Nginx is checked before it restarts.** A bad config fails `nginx
  -t`, and the running Nginx keeps serving the old one.
- **Every run restarts Nginx and `bun-app`** (unless
  `SKIP_BUN_APP=1`), so a new Bun or config takes effect. Plan re-runs
  like a short deploy.

## What runs

| Unit | Runs as | Does |
| --- | --- | --- |
| `nginx.service` | root master, `www-data` workers | listens on 80 (443 after Certbot), serves the web root, proxies to Bun |
| `bun-app.service` | `bun-app`, sandboxed | `bun` in `/srv/app` on `127.0.0.1:3000` |
| `cloudflare-update-ips.timer` | | starts the updater daily, delayed at random by up to an hour |
| `cloudflare-update-ips.service` | root, sandboxed | fetches Cloudflare's IP ranges, rewrites the lists, reloads Nginx |
| `snap.certbot.renew.timer` | root | renews certificates (the Certbot snap's own timer) |

- **UFW** denies incoming traffic except the SSH port(s), rate-limited,
  and `Nginx Full` (80 and 443).
- **Only Nginx reaches Bun.** Bun binds loopback, so port 3000 is closed
  to the network even without UFW.
- Each sandbox is listed directive by directive in
  [Security](security.md#sandboxing).

## Nginx layout

All under `/etc/nginx/`:

| File | From | Re-run |
| --- | --- | --- |
| `sites-available/default` | the installer's site: static files, `/api/`, `/healthz`, Bun fallback | kept while its marker line stays |
| `snippets/bun-proxy.conf` | `proxy_pass` to `127.0.0.1:3000` and the proxy headers | kept |
| `conf.d/bun-connection-upgrade.conf` | the `$bun_connection_upgrade` map for WebSockets | kept |
| `conf.d/bun-cloudflare.conf` | real client IP, `$bun_cloudflare_edge`, `$bun_cloudflare_deny` | kept |
| `snippets/cloudflare-only.conf` | 403 for requests that bypass Cloudflare (include it to turn on) | kept |
| `cloudflare/real-ip.conf`, `edge-ips.conf` | Cloudflare's ranges | generated by the updater |

- **The site includes the snippets.** `@bun` (the fallback of
  `location /`), `/api/` and `/healthz` all reach Bun through
  `snippets/bun-proxy.conf`, which uses the map in `conf.d/`.
- **`conf.d/` files load for every site,** so the real client IP applies
  to your own server blocks too. See [Cloudflare](cloudflare.md).
- **With `SKIP_BUN_APP=1`** Ubuntu's stock site stays, and only the
  Cloudflare files are installed.

## Files and re-runs

Every file the installer writes, and what a later run does with it.
Paths in the [stable surface](compatibility.md#installed-paths-and-names)
keep their name and meaning across 1.x; the others may change.

| Path | Re-run | Stable |
| --- | --- | --- |
| `/usr/local/bin/bun`, `bunx` | replaced when its version differs from the target | yes |
| `/srv/app` | sample written only if neither `server.ts` nor `package.json` exists | yes |
| `/var/lib/bun-app` (= `/srv/app/data`), `/var/cache/bun-app` | systemd's; never touched | yes |
| `/var/www/app/dist/index.html` | written with the sample app only | no |
| `/var/www/html/index.html` (`SKIP_BUN_APP=1`) | kept | no |
| `/etc/systemd/system/bun-app.service` | kept | yes |
| `/etc/bun-app.env` | kept | yes |
| Nginx files above | see [Nginx layout](#nginx-layout) | yes |
| `/usr/local/sbin/cloudflare-update-ips` and its units | kept | yes |
| `/var/lib/app-info/application.info` | rewritten | yes |
| `INSTANCE_ID` in `/etc/environment` | the same value, one line | yes |
| `/etc/update-motd.d/00-custom` | kept | no |
| `/etc/logrotate.d/bun-installer` | kept | yes |
| `/var/log/bun-installer.log` | appended | yes |

- **Kept** means the installer prints `Kept existing <path>` and leaves
  the file as it is, edits included. Delete it and re-run to get the
  current template; see Operations, [Re-running the
  installer](operations.md#re-running-the-installer).
- **Template fixes reach new installs only,** for the same reason.
